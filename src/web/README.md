# Веб-интерфейс

Один процесс: FastAPI + Jinja + htmx, фоновые задачи (браузер) и планировщик.

```bash
make web-local     # http://127.0.0.1:8080
```

## Страницы

| Путь | Что делает |
| --- | --- |
| `/` | Сводка: сколько собрано/оценено/готово к отклику, активное резюме, ключевые настройки, последние прогоны |
| `/vacancies` | Таблица вакансий с оценкой, обоснованием и статусом отклика; фильтры (оценка от, только оценённые, без отклика, поиск, сортировка); выбор галочками и «Откликнуться на выбранные» |
| `/applications` | Отклики бота: когда, на что, статус (`applied` / `skipped_questions` / `skipped_low_score` / `failed`), оценка и комментарий |
| `/resume` | Импорт резюме по ссылке hh.ru, список сохранённых, выбор активного, разбор по разделам (опыт, образование, сертификаты, о себе) и весь распознанный текст |
| `/runs` | История прогонов: задача, ручной/по расписанию, статус, результат или ошибка |
| `/settings` | Все настройки приложения, сгруппированные; пометка «изменено» у отличий от YAML |

Панель задач и журнал видны на всех страницах: выбираешь вариант
(собрать / оценить / откликнуться по порогу / полный цикл / войти в hh.ru)
и жмёшь «Старт». Выбор запоминается в localStorage и переживает перерисовку панели.

## Индикатор нейросети

Лампочка есть в панели задач (компактно: точка + название модели, состояние — в
подсказке), на обзоре и в блоке «Нейросеть» настроек (полностью: точка, текст,
модель, задержка, кнопка «проверить»). Зелёная — связь есть, красная — нет
(с причиной: ключ отклонён, сервер недоступен, таймаут, лимит), серая — выключена.

Проверка ([`src/llm/health.py`](../llm/health.py)) дёргает список моделей — без
расхода токенов, с коротким таймаутом и без ретраев. Опрос — раз в 10 секунд
(`LLM_POLL_SECONDS`), кэш чуть короче интервала, поэтому несколько лампочек на
странице делят одну проверку. Сохранение настроек сбрасывает кэш.

> Важно: фрагмент, который возвращает `/actions/llm-health`, **не** содержит
> `hx-trigger="load"` — иначе каждая подстановка мгновенно запускала бы новый
> запрос, и эндпоинт получал бы десятки запросов в секунду.

Поле «Модель» — выпадающий список, который подгружается с самого эндпоинта
(`GET /actions/llm-models` → `list_models()`, тот же кэш, что у лампочки).
Если список получить не удалось, поле остаётся текстовым, а кнопка рядом
пробует запросить его снова. Своё значение, которого нет в списке, не теряется.

Статика отдаётся с `Cache-Control: no-cache` и ссылками вида `app.css?v=<mtime>` —
иначе браузер держит старую таблицу стилей и страница выглядит «без CSS».

## Остановка задач

«Стоп» работает в три слоя, потому что браузерные вызовы могут висеть дольше
любого чекпоинта:

1. хуки остановки (`ctx.on_stop`) срабатывают в момент нажатия — сборщик
   прерывает скролл сразу, а не в конце страницы;
2. кооперативные проверки `ctx.raise_if_stopped()` между шагами;
3. через 4 секунды (или по второму нажатию — кнопка становится
   «Остановить принудительно») задача отменяется жёстко.

## Как это устроено

```text
main.py web  →  src/web/app.py (lifespan: БД → SettingsService → TaskManager → Scheduler)
                 ├── routes/pages.py    HTML-страницы
                 ├── routes/actions.py  запуск задач, настройки, резюме, SSE (/actions/events)
                 ├── tasks.py           одна задача за раз, лог, прогресс, стоп, подтверждение
                 ├── jobs.py            collect / score / apply / resume_import / login / pipeline
                 └── scheduler.py       периодический запуск pipeline
```

Поиск настраивается одним полем «Что ищем» — это параметр `text` в URL hh.ru.
Остальные фильтры (город, опыт) берутся из `hh_autoscroller.search_url` в YAML,
который служит шаблоном: меняется только запрос, прочие параметры сохраняются.

Настройки: YAML — дефолты, таблица `app_settings` — переопределения.
Схема полей объявлена в [`src/settings.py`](../settings.py) (`FIELDS`); чтобы добавить
настройку, достаточно дописать туда `SettingField` — форма и валидация появятся сами.
Флаг `advanced=True` прячет поле в спойлер «Тонкая настройка» (так убраны параметры
скролла); спойлер раскрывается сам, если какое-то значение внутри отличается от дефолта.

`SettingsService` отдаёт готовые дата-классы (`browser_config()`, `scroller_config()`,
`llm_config()`), поэтому сервисы не знают, откуда пришло значение.

## Живые обновления

`/actions/events` — SSE-поток: `snapshot` (лог текущей задачи при подключении),
`log`, `progress`, `started`, `finished`, `stopping`.
[`static/app.js`](static/app.js) дописывает журнал, двигает прогресс-бар и
перерисовывает панель через htmx. htmx лежит локально (`static/htmx.min.js`) —
интерфейс работает без интернета.

## Вход в hh.ru

Кнопка «Войти в hh.ru» открывает реальное окно Chrome на странице входа и ждёт
подтверждения кнопкой «Я вошёл» (до 15 минут). После подтверждения сессия
сохраняется в `data/storage_state.json`, профиль — в `data/browser-profile`.
Работает, когда браузер и веб-интерфейс на одной машине.

## Очереди задач

Две независимые очереди: `main` (сбор, оценка, отклики, вход, обновление
резюме — по одной задаче за раз) и `activity`
([имитация активности](../activity/README.md)), которая работает параллельно.
«Стоп» действует на конкретную очередь.

## Расписание

Три независимых цикла, каждый со своим интервалом:

| Цикл | Настройки | Очередь |
| --- | --- | --- |
| Сбор → оценка → отклики | `schedule.enabled`, `schedule.interval_minutes`, флаги этапов | `main` |
| Имитация активности | `schedule.activity_enabled`, `schedule.activity_interval_minutes` | `activity` |
| Обновление резюме | `schedule.resume_touch_enabled`, `schedule.resume_touch_interval_hours` | `main` |

Отклики по расписанию уходят только если `apply.mode = auto` — в ручном режиме
этап пропускается с записью в журнал. Если очередь занята, запуск не теряется,
а откладывается на 5 минут.

## Остановка сервера

Ctrl+C завершает процесс за ~2 секунды даже с открытыми вкладками, без трейсбека.
Поток журнала (SSE) бесконечен по своей природе, поэтому uvicorn ждал бы его вечно
(«Waiting for connections to close»); обработчик сигнала в
[`serve()`](app.py) выставляет `app.state.shutting_down`, потоки закрываются
сами на ближайшем heartbeat (3 с), а `timeout_graceful_shutdown` в 5 секунд
страхует остальное.

`KeyboardInterrupt` перехватывается в [`main.py`](../../main.py) (`run()`) — это
штатный способ остановки, а не авария. Там же сторожевой таймер: если
подвисший не-демон поток (например, недобитый драйвер Playwright) не даёт
интерпретатору выйти, процесс завершается принудительно через 3 секунды.
Чтобы драйвер не оставался в живых при жёсткой отмене задачи, `BrowserConnector`
в `_cleanup` доводит закрытие до конца даже под `CancelledError`.

## Доступ

По умолчанию слушает `127.0.0.1` без авторизации. Если открываете наружу,
задайте `web.token` в конфиге (или `WEB_TOKEN`): первый заход по
`?token=...` ставит cookie, без токена — 401.
